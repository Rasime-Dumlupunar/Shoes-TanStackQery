# 🛍️ Ayakkabı E-Ticaret Web Sitesi

Bu proje, **React** ve **TypeScript** kullanılarak geliştirilmiş tam işlevsel bir ayakkabı e-ticaret web sitesidir. Tasarım, bir Figma prototipinden ilham alınarak oluşturulmuştur. Web sitesi, ürün listeleme, fiyatlandırma, indirimler, yeni ürünler, detaylı ürün sayfaları ve gelişmiş filtreleme özellikleri içermektedir.

## 📦 Kütüphaneler ve Araçlar

- **react-router-dom**: Sayfalar arasında kesintisiz gezinme ve yönlendirme.
- **tailwind**: Verimli ve duyarlı tasarımlar için stil yapısı.
- **axios**: HTTP istekleri ve API entegrasyonu.
- **json-server**: Ürün verilerini simüle etmek için sahte bir backend API.
- **@tanstack/react-query**: Verimli veri alma, önbellekleme ve senkronizasyon.
- **xss**: Kullanıcıdan gelen içeriği temizleyerek XSS saldırılarını önleme.

# 🛍️ Shoes E-Commerce Website

This project is a fully functional shoe e-commerce website developed using **React** and **TypeScript**. The design was inspired by a Figma prototype. The website includes features such as product listing, pricing, discounts, new arrivals, detailed product pages, and advanced filtering options.

## 📦 Libraries and Tools

- **react-router-dom**: For seamless navigation and routing between pages.
- **tailwind**: For efficient and responsive styling.
- **axios**: To handle HTTP requests and API integration.
- **json-server**: To simulate product data using a mock backend API.
- **@tanstack/react-query**: For efficient data fetching, caching, and synchronization.
- **xss**: To sanitize user input and prevent XSS attacks.
